      ## Details to check at the site measure

      - Opening dimensions and whether the existing frame can stay.
      - Door code, configuration, glazing and new hardware.
      - Entrance exposure and the manufacturer’s finishing and care requirements.
      - Who will arrange finishing, and when it needs to happen in the installation sequence.
      - Any surrounding work to be arranged separately.

      ## Finishing and security screens

      **Painting, staining or sealing:** doors and timber components require finishing by others.

      **Refitting existing security screens:** in most cases, existing security screen doors are unlikely to be compatible with the new door frame. We don’t refit existing screens, so any replacement or alterations will need to be arranged separately.

      Read the complete [service exclusions](/what-we-do/) when planning the replacement.
