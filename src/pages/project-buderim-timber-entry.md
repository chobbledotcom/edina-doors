      ## What would need to be recorded on site?

      - The actual opening dimensions and the existing frame assessment.
      - The selected door code, configuration, glazing and new hardware.
      - The exposure of the entrance and the manufacturer’s finishing and care requirements.
      - Who will arrange finishing, and how that work fits the installation sequence.
      - Any surrounding work that sits outside Edina’s scope.

      No door code, timber species, price, lead time or completion time has been selected for this fictional brief.

      ## The scope boundary matters

      **Painting, staining or sealing:** doors and timber components require finishing by others.

      **Refitting existing security screens:** in most cases, existing security screen doors are unlikely to be compatible with the new door frame. We don’t refit existing screens, so any replacement or alterations will need to be arranged separately.

      These are existing Edina exclusions, not extra services implied by this concept. Read the complete [Edina Doesn’t list](/what-we-do/).
